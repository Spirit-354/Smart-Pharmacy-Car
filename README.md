# Smart-Pharmacy-Car
基于机器视觉的智慧药房智能送药小车
> CRAIC中国机器人及人工智能大赛 · 智慧药房赛道参赛作品
> 参赛人员：马乐杉 杨盛炜

## 项目简介
本作品以小型智能车为硬件载体，融合嵌入式控制、机器视觉识别、自主循迹、超声波避障与路径规划算法，搭建智慧药房室内药品自动配送系统。
小车可模拟药房真实环境，完成自主导航、点位标签识别、药品转运、精准停靠、智能避障全流程任务，解决传统药房人工配送效率低、动线繁琐、人力成本高、易出错等痛点。
项目结构轻量化、扩展性强，适配校园模拟药房、小型医疗机构等场景，为智慧医疗无人配送提供低成本解决方案。

## 硬件配置
- 主控：STM32单片机 / 树莓派
- 感知模块：USB摄像头、超声波避障模块、红外循迹传感器
- 执行模块：直流减速电机、舵机
- 供电：锂电池
